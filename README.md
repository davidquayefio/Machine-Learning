# Machine Learning Projects

This repository is a collection of independent machine-learning projects. Each project lives in its own top-level folder and includes its own README, dependencies, data (when appropriate), and source code.

## Projects

### Hyperparameter Search

Random Forest hyperparameter tuning with scikit-learn GridSearchCV and RandomizedSearchCV, scikit-optimize Gaussian-process optimization, Hyperopt, and Optuna.

- Project documentation and setup: [Hyperparameter Search/README.md](Hyperparameter%20Search/README.md)
- Training and test datasets: `Hyperparameter Search/data/`
- Python scripts and generated graphs: `Hyperparameter Search/src/`

## Adding a project

Create a new folder at the repository root for each machine-learning project. Keep that project's instructions and dependencies inside its folder so projects can be installed and run independently.
